# homebrew-tap

Homebrew tap for my public tools. One tap, many projects — each project owns a
single file here and nothing else.

## Installing something from this tap

```bash
brew install mfreydl/tap/<project>
```

`mfreydl/tap` is shorthand Homebrew expands to this repository, so there is no
`brew tap` step. To browse what is available:

```bash
brew tap mfreydl/tap && brew search mfreydl/tap
```

## Layout

```
Casks/      prebuilt binaries (most Go/Rust CLIs land here)
Formula/    build-from-source packages, if any
```

Homebrew now prefers a **cask** for a project that ships prebuilt binaries;
formulae are for source builds. Both directories can coexist in one tap.

## Adding another project

Nothing needs to change in this repository — the project's own release
pipeline writes its file here. In that project's `.goreleaser.yaml`:

```yaml
homebrew_casks:
  - name: <project>
    repository:
      owner: mfreydl
      name: homebrew-tap
      token: "{{ .Env.TAP_TOKEN }}"
    directory: Casks
```

Two requirements for sharing the tap safely:

1. **The `name` must be unique across every project here.** Two projects using
   the same name will silently overwrite each other's file.
2. **`TAP_TOKEN` must be a token with write access to this repository.** A
   workflow's default `GITHUB_TOKEN` is scoped to its own repository and cannot
   push here.

If the binaries are not code-signed, include the quarantine-stripping install
hook — macOS blocks unsigned downloads on first run, and Homebrew does not
clear that attribute for casks:

```yaml
    hooks:
      post:
        install: |
          if system_command("/usr/bin/xattr", args: ["-h"]).exit_status == 0
            system_command "/usr/bin/xattr", args: ["-dr", "com.apple.quarantine", "#{staged_path}/<project>"]
          end
```

Then add a row to the table above.

## Note

Files under `Casks/` and `Formula/` are generated by GoReleaser and carry a
`DO NOT EDIT` header. Change the project's release config, not the file here —
the next publish overwrites it.
